React Hooks are a feature introduced in React 16.8 that allow developers to use state
and other React features without writing a class component. Before Hooks, state and
lifecycle methods were only available in class-based components, which often led to
complex and hard-to-maintain code.

The most commonly used React Hook is useState. The useState Hook allows functional
components to store and update local state. It returns an array with two elements:
the current state value and a function to update that state.

Another important Hook is useEffect. The useEffect Hook is used to perform side effects
in functional components. Side effects include data fetching, subscriptions, timers,
and manual DOM manipulation. By default, useEffect runs after every render, but this
behavior can be controlled using a dependency array.

React also provides the useContext Hook, which allows components to consume values
from a React Context without using a Consumer component. This makes it easier to
share data such as themes or user authentication state across the component tree.

Custom Hooks are a powerful feature that allows developers to extract reusable logic
into standalone functions. A custom Hook is a JavaScript function whose name starts
with "use" and can call other Hooks inside it.

React Hooks follow two important rules. First, Hooks must be called at the top level
of a React function, not inside loops, conditions, or nested functions. Second, Hooks
must only be called from React function components or custom Hooks.
